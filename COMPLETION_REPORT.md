## 🎓 How to Use New Features

### Multi-Room Booking
```
1. Open BookingForm
2. Toggle "Modo Multi-Habitación" switch
3. Select quantity for each room type:
   - Estándar King Size
   - Doble Queen Size
   - Suite
4. View real-time cost calculation
5. Generate confirmation with breakdown
```

### WhatsApp Direct Chat
```
1. Click "Abrir WhatsApp" button in BookingForm
2. Select country code (default: +52 México)
3. Enter phone number (min 8 digits)
4. Click "Abrir Chat"
5. WhatsApp opens directly to that number
```

### Building Android APK
```bash
# Method 1: NPM Scripts
npm run build
npm run cap:sync
cd android && ./gradlew assembleDebug

# Method 2: Automated Script
./build-apk.sh

# APK Location:
android/app/build/outputs/apk/debug/app-debug.apk
```
